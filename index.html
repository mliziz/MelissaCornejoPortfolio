Mirror Magica

Current work

UI/UX • Visual direction • Interface system

I’m exploring a soft “magical UI” style: readable typography, clear hierarchy, and expressive interface elements that feel integrated with the world. Mirror Magica is a personal project that I’m leading the design for, from wireframes to implementation in Unity. It is a personal exploration of self-image and identity through interactive media. I was able to create this video game with the help of my team and Gameheads, which will be launching on itch.io soon!
